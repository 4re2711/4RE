你的词汇学习空间

词典、例句、题库来自 explain-vocabulary 技能。检索由网站服务完成，无需安装软件或填写 API 密钥。

“学习笔记”是 AI 辅助整理的补充讲解与原创例句，不是词典原文或官方考试考点。词典辨析只在有对应资料时显示；原始词典文本始终可以展开核对。

题库来自大英赛，作为词汇巩固材料，不标作考研或四六级真题。收藏与最近查询仅保存在当前浏览器；可以导出生词本留存。

这是临时分享站点，需要分享者保持电脑开机联网。临时网址改变后，旧网址下的生词本不会自动迁移，请及时导出留存。
